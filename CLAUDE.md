# Фабрика исторических видео — правила проекта

Локальная фабрика длинных (8–9 минут) горизонтальных YouTube-видео по ИСТОРИИ.
Владелец — не программист: всё объяснять **просто и по-русски**. Сами видео — **на английском**.

План этапов и текущий статус: `docs/PLAN.md`. После каждого этапа — запуск, тест,
показ результата и ожидание «ок» владельца. Не переходить к следующему этапу без «ок».

## Жёсткие ограничения

- Только бесплатные инструменты, всё работает локально на ноутбуке владельца
  (Windows 11, NVIDIA RTX 4050 Laptop 6 ГБ). Никаких платных API, подписок,
  внешних генераторов картинок / видео / голоса.
- Единственный «умный» компонент — Claude Code: субагенты через `claude -p --agent <имя>`.
- Музыки НЕТ. Только голос. Звуковые эффекты — только если владелец попросит.
- Видео: английский, 8–9 минут (≈1250–1400 слов озвучки), 16:9, 1920x1080, 30 fps.
- Shorts: 3–5 штук, 30–55 с, 1080x1920, **пересобираются** вертикально, а не обрезаются.
- Автозагрузки на YouTube нет: финальный просмотр делает владелец.
- Ответы владельца из ТЗ не переспрашивать.

## Стек

- **Remotion (React)** — папка `video/`. Следовать правилам skill `remotion-dev/skills`
  (`.claude/skills/`).
- **Python 3.12** (Kokoro не работает на 3.13+), отдельный `.venv`.
- **Озвучка Kokoro** (`kokoro==0.9.4`). Время каждого слова — прямо из Kokoro
  (`result.tokens`: `start_ts` / `end_ts`).
  **НИКОГДА не использовать faster-whisper / ctranslate2**: Smart App Control в Windows 11
  блокирует их DLL (WinError 4551). Запасные движки: Piper, затем edge-tts.
- **Произношение**: словарь `config/pronunciations.json`; misaki принимает запись
  `[слово](/фонемы/)`. Все имена собственные в тексте проверяются и добавляются в словарь.
- **FFmpeg** — сборка, громкость, проверки.
- **Веб-страница**: FastAPI + один HTML-файл, запуск двойным щелчком `start.bat`.
- GPU — там, где ускоряет, с автоматическим откатом на CPU при любой ошибке.

## Озвучка: как это устроено (этап 1)

- Код: `factory/tts/`. Главная функция — `factory.tts.narrate_to_files(text, wav, voice=…)`:
  пишет WAV и рядом `.words.json` со временем каждого слова.
- Слова со временем обязаны в точности совпадать со словами текста после
  `factory.tts.text.normalize()` — движок сам это проверяет и падает при расхождении.
- Словарь: `config/pronunciations.json`, для каждого слова два варианта — `us` (голоса `a*`)
  и `gb` (голоса `b*`). Ключ — одно слово. Команды:
  `python -m factory.tts.cli check | audit ФАЙЛ | phonemes "текст" | add СЛОВО --us … --gb …`.
- `audit` показывает слова, которые Kokoro «угадал» (нет ни в его словаре, ни в нашем).
  Каждое такое имя собственное агент обязан проверить и добавить в словарь.
- Римские цифры после имени читаются сами («Thutmose III» → «the Third», «World War II» →
  «Two»). Исключение — одиночная «I»: её легко спутать с местоимением, поэтому в тексте
  озвучки писать «Darius the First», а не «Darius I».
- Темп у голосов разный (144–175 слов/мин), поэтому число слов на 8–9 минут считается от
  темпа выбранного голоса, а не берётся жёстко 1250–1400.
- Модели лежат в `models/` внутри проекта (не в профиле пользователя); когда они скачаны,
  озвучка работает без интернета.
- Версии библиотек зафиксированы: `requirements.in` → `requirements.txt` (собран для Windows).
- Проверка записей распознаванием речи (Whisper) делалась только при разработке и в продукт
  не входит.

## Изображения и источники (строго)

- Внешние изображения — ТОЛЬКО public domain или CC0.
- Разрешённые архивы: Wikimedia Commons (лицензию проверять через API metadata, брать
  только PD/CC0), The Met Open Access, Art Institute of Chicago, Smithsonian Open Access,
  Rijksmuseum, Library of Congress (только «no known restrictions», с проверкой).
- Каждый файл → `sources.txt`: URL, автор, дата, лицензия. **Нет лицензии — нет файла.**
- Скачанное кэшируется (`cache/`).
- Карты: современная география — Natural Earth (public domain). Исторические границы
  рисуются кодом по источникам и подписываются «approximate».
- Без лиц реальных живых людей, без чужих логотипов, без кадров из фильмов и чужих каналов.

## Исторический контент (строго)

- Каждый факт, дата, число и цитата — с надёжным источником, который агент **реально
  открыл**: научные книги и статьи (университетские издательства, JSTOR / открытые статьи),
  энциклопедии (Britannica; World History Encyclopedia — с осторожностью), сайты музеев и
  архивов, первоисточники.
- НЕ источники: блоги, форумы, «топ-10» сайты, YouTube, соцсети.
- Каждое утверждение имеет статус: **факт / спорно / легенда / миф**. Спорное и легенды
  так и называются в озвучке.
- Числа (армии, жертвы, население) — диапазоном и с источником, без преувеличений.
- Тяжёлые темы (войны, геноциды, рабство, казни) — уважительно: без смакования насилия,
  без героизации преступлений, без оправдания ненависти; по правилам YouTube о насилии
  и экстремизме.
- Без «презентизма»-оценок без пояснений. Догадки не выдавать за факты.
- Простой язык: понятно школьнику; термины и имена объясняются сразу
  («a pharaoh — Egypt's king»). Простота текста проверяется автоматически.

## Сценарий и удержание

- Хук в первые 15 секунд: интрига / вопрос / неожиданный факт + обещание ответа. Без кликбейта.
- Каждые 60–90 секунд — «повторный хук» (новый вопрос, поворот, открытая петля).
- У каждого видео своя структура (хроника, расследование, «день из жизни», «взлёт и
  падение», «миф vs правда», «5 причин…», «глазами участника», «что если…», «сравнение
  эпох», обратный отсчёт…). Фабрика помнит последние структуры и не повторяет их подряд.
- 5–7 глав, у каждой своя мини-кульминация.
- Финал: вывод + мост к следующей теме. Никаких «подпишитесь» в середине.
- Четыре поднаправления (выбирается для каждого видео): древние цивилизации; войны и
  сражения; загадки и тайны истории; повседневная жизнь людей в прошлом.

## Визуал

- Кадр всегда заполнен: крупный главный объект, фон-«среда», движение камеры.
  Никаких пустых экранов с маленькой фигуркой.
- У каждого кадра свой фон; соседние кадры никогда не одинаковые (ни фон, ни тип кадра).
- Смена картинки каждые 4–8 секунд. Типы кадров: карта с анимированными стрелками и
  границами, таймлайн, архивное изображение с Ken Burns и подписью, сцена-иллюстрация кодом,
  персонаж-рассказчик, сравнение «тогда / сейчас», цитата из первоисточника, схема
  (битвы, города, торговые пути), инфографика с числами.
- Субтитры снизу: 2 строки, крупно, с подсветкой слова + файл `.srt`. Всё важное —
  в безопасной зоне.
- Единые палитры и шрифты — в `video/src/style.ts`. Стили меняют палитру, шрифт и
  обработку картинки, но **тексты (заголовки, подписи, субтитры) всегда чёткие —
  отдельным слоем поверх обработки**.
- Стиль и голос хранятся в настройках и могут меняться для отдельного видео.

## Технические уроки (это уже ломалось — не повторять)

- Windows: `setup.bat` + `start.bat` + `update.bat` (git pull). `.bat` — в CRLF, первая
  строка после `@echo off` — `chcp 65001 >nul`; внутри `if ( … )` не писать скобки в `echo`.
- Claude Code ставить через `winget install Anthropic.ClaudeCode` (npm-версия даёт
  «claude.exe is not a valid application»).
- Скачанные `.bat` блокирует Smart App Control → в README: «Открыть в терминале» →
  `Get-ChildItem -Recurse | Unblock-File` → `.\setup.bat`.
- Папка проекта — на диске C:, не Рабочий стол / OneDrive, без кириллицы в пути.
- Медленный интернет: pip с `--resume-retries 100 --timeout 120`; PyTorch по умолчанию
  обычный (≈200 МБ), версия для видеокарты — отдельным `install_gpu.bat`; модели
  скачиваются заранее отдельной командой с докачкой.
- Рендер Remotion: на Windows сначала `--gl=angle`, затем `swiftshader`; на Linux без
  GPU — `swiftshader` / `egl` (**НЕ `swangle`** — в 4 раза медленнее).
- Шум / зерно — готовые картинки-текстуры, а не `feTurbulence` в каждом кадре.
- Итоговый файл — H.264 **yuv420p** (не yuvj420p) с `-movflags +faststart`.
- Громкость −16…−13 LUFS, пики ≤ −1 dB. Видео = звук = сумма кадров. Субтитры = текст на 100 %.
- Рендер по главам (параллельно, с продолжением после сбоя); показывать оценку времени.
- Упавший шаг повторяется до 3 раз; лог — на русском.

## Архитектура

- **Скрипты (не агенты)**, папка `factory/`: озвучка, произношение, время слов, загрузка и
  проверка лицензий изображений, рендер по главам, склейка, проверки, нарезка Shorts, упаковка.
- **Субагенты** (`.claude/agents/`, минимум инструментов, **НИКОГДА не задают вопросов
  владельцу**): idea-researcher, outline-writer, scriptwriter, fact-checker,
  image-researcher, storyboard-agent, shorts-editor, packager, quality-reviewer.
  Результат агента — файл JSON, который скрипт проверяет по схеме.
- Состояние каждого видео — `output/<дата>_<тема>/state.json`; каждый шаг сценария
  работы ждёт решения владельца (кроме шага «Производство»).

## Главы с таймкодами

- `description.txt`: первая строка «0:00 …», минимум 3 главы, каждая ≥ 10 с, по возрастанию.
- Время глав — из реальной озвучки (время первого слова главы), не из оценок.
- Названия глав ≤ 40 символов, короткие и интригующие.
- Проверка: таймкоды совпадают с началом глав в `video.mp4` (± 1 с); то же для `chapters.json`.

## Критерии «готово»

Звук и картинка синхронны; субтитры без сдвига; текст не выходит за кадр; у каждого
изображения есть PD/CC0-лицензия в `sources.txt`; каждый факт с источником и статусом;
фоны и типы кадров не повторяются подряд; нет пустых кадров; громкость ровная, нет
обрезанных слов; видео точно соответствует подтверждённой раскадровке; Shorts
самодостаточны и с хуком.

## Выход (в папке видео)

`video.mp4`, `thumbnail_1..3.png`, `title.txt` (3 варианта), `description.txt` (с главами),
`chapters.json`, `tags.txt`, `captions.srt`, `sources.txt`, `script.txt`, `outline.json`,
`storyboard.json`, `shorts/short_1..5.mp4` (+ названия / описания).

## Разработка

- Разработка идёт в облачном Linux без видеокарты; ноутбук владельца — Windows 11.
  `.bat`-файлы и ускорение на видеокарте здесь проверить нельзя — честно говорить об этом
  и просить владельца запустить их у себя.
- Проверка окружения: `python scripts/check_env.py` (на Windows — `check_env.bat`).
- Автотесты: `pytest` (с озвучкой: `pytest -m slow`; без неё: `pytest -m "not slow"`).
- В облаке PyTorch ставится с PyPI (`uv pip install torch`): файловый сервер pytorch.org
  (download-r2.pytorch.org) в окружении закрыт.
- Папка `headroom/` (git-подмодуль) к фабрике не относится — не трогать.
