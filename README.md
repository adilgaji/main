# Фабрика исторических видео

Программа, которая на вашем ноутбуке делает длинные (8–9 минут) YouTube-видео по истории:
сама предлагает тему, пишет и проверяет текст, озвучивает, рисует карты и иллюстрации,
подбирает архивные изображения с открытой лицензией и собирает готовое видео с обложками,
описанием и Shorts. Каждый важный шаг ждёт вашего решения.

> **Статус: в разработке.** Готов этап 0 (проверка компьютера и план).
> План и структура — в [docs/PLAN.md](docs/PLAN.md).
> Полная инструкция по установке появится на последнем этапе.

## Проверить ноутбук уже сейчас (по желанию)

Проверка ничего не устанавливает и не меняет — только смотрит, чего не хватает.

1. Нажмите **Win + X** и выберите **«Терминал»**.
2. Если Git ещё не установлен:

   ```
   winget install Git.Git
   ```

   Закройте Терминал и откройте его снова.
3. Скачайте проект на диск C: (не на Рабочий стол и не в OneDrive):

   ```
   git clone -b claude/nifty-bell-79c69y https://github.com/adilgaji/main C:\history-factory
   ```

4. Перейдите в папку и запустите проверку:

   ```
   cd C:\history-factory
   Get-ChildItem -Recurse | Unblock-File
   .\check_env.bat
   ```

Появится список с пометками:

- `[ OK ]` — всё хорошо;
- `[ !! ]` — замечание, работать можно;
- `[НЕТ!]` — нужно исправить; рядом написана готовая команда.

Результат сохраняется в `logs\env_report.json` — его можно прислать Claude.

## Если .bat-файл не запускается

Windows 11 («Интеллектуальное управление приложениями», Smart App Control) иногда блокирует
скачанные файлы. Откройте папку проекта, щёлкните правой кнопкой по пустому месту →
**«Открыть в терминале»** и выполните:

```
Get-ChildItem -Recurse | Unblock-File
```

После этого запустите файл ещё раз.
