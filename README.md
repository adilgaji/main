# 🧬 Фабрика YouTube Shorts «Биология тела»

Программа делает короткие вертикальные ролики (30–55 с, 1080×1920, на английском) о том,
как работает тело человека: гормоны, мышцы, мозг, сердце, сон, стресс.
Стиль — 2D-объяснялка: человечек-гид, схемы тела, органы, клетки, молекулы, графики.
Всё рисуется кодом, работает на вашем компьютере, без платных сервисов.

Вы только принимаете решения на веб-странице. Агенты Claude пишут текст и проверяют факты,
программа озвучивает, делает субтитры, собирает видео, обложку и описание.
**Автозагрузки на YouTube нет** — финальный просмотр и загрузка за вами.

## 1. Установка (один раз)

Нужно: Windows 10/11 (или Linux), видеокарта NVIDIA (необязательно, но быстрее), ~15 ГБ места.

1. Откройте **PowerShell** и установите недостающее (каждая команда — одна строка):

```bash
winget install Python.Python.3.12
```

```bash
winget install OpenJS.NodeJS.LTS
```

```bash
winget install Gyan.FFmpeg
```

```bash
winget install eSpeak-NG.eSpeak-NG
```

```bash
winget install Git.Git
```

```bash
winget install Anthropic.ClaudeCode
```

(Это официальная версия Claude Code для Windows. Не ставьте его через `npm`: на части компьютеров npm-версия выдаёт ошибку
«claude.exe is not a valid application for this OS platform». Если npm-версия уже стоит, сначала удалите её:
`npm uninstall -g @anthropic-ai/claude-code`.)

2. **Закройте и заново откройте PowerShell**, проверьте `claude --version` (должен показать номер версии).
   Проверка установки: `claude doctor`.
   Затем один раз войдите в Claude Code: наберите `claude`, следуйте подсказкам (откроется браузер), потом закройте.
   Если `winget` не сработал — запасной способ (две команды в одном окне, установщик молчит 1–2 минуты, это нормально):
   `[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12`, затем `irm https://claude.ai/install.ps1 | iex`.
3. Обновите драйвер NVIDIA (GeForce Experience или nvidia.com) — нужен драйвер с поддержкой CUDA 12.8.
4. Скачайте проект (зелёная кнопка **Code → Download ZIP** на GitHub), распакуйте.
5. Откройте папку проекта, щёлкните правой кнопкой по пустому месту → «Открыть в терминале» и выполните
   `Get-ChildItem -Recurse | Unblock-File` (снимает блокировку Windows со скачанных файлов), затем `.\setup.bat`.
   Он всё поставит (10–30 минут, ~2 ГБ) и в конце покажет проверку:
   `[OK]` — всё хорошо, `[!!]` — работает, но медленнее, `[НЕТ]` — нужно установить (команда будет написана).

Проверить компьютер можно в любой момент: `.venv\Scripts\python scripts\check_env.py`.

6. (По желанию, можно позже) **Ускорение видеокартой:** запустите `install_gpu.bat` — докачает PyTorch для NVIDIA (~2,8 ГБ).
   Без него всё работает, озвучка просто идёт на процессоре (~30 с на ролик).

Совет: держите папку проекта на диске C: (например `C:\bodyshorts`), не на Рабочем столе/в OneDrive — иначе OneDrive будет выгружать гигабайты.

## 2. Запуск

Дважды щёлкните **`start.bat`** — откроется страница `http://localhost:8765`.
Окно с чёрным экраном не закрывайте, пока работаете (закрыли — программа остановилась).

## 3. Как сделать ролик

Нажмите **▶ Запустить**. Дальше — 5 шагов, каждый ждёт вашего решения:

| Шаг | Что происходит | Ваши кнопки |
|---|---|---|
| 1. Тема | Вводите тему сами **или** агент ищет актуальную тему в интернете и предлагает одну с обоснованием | «Подтвердить», «Сделать заново» (прежние темы не повторяются) |
| 2. Текст | Сценарист пишет текст простыми словами, проверяющий сверяет каждый факт с научными источниками. Видите текст, перевод, таблицу «факт → уровень доказанности → источник» | «Подтвердить», «Переписать» (с замечаниями), «Править вручную» |
| 3. Раскадровка | Делается озвучка, затем таблица кадров: время, что на экране, точный текст, переход. Можно послушать голос | «Подтвердить и начать работу», «Переделать», ✎ у каждого кадра |
| 4. Производство | Озвучка → субтитры → сборка сцен → рендер → проверки → описание, теги, обложка → контроль качества. Без вопросов, прогресс на странице, упавший шаг повторяется до 3 раз | — |
| 5. Результат | Видео, 3 названия, описание, теги, обложка, отчёт контроля качества | «📂 Открыть папку» |

### Формат: Shorts или длинное видео
На первом экране выберите **Shorts** (вертикальное, 30–55 с, бесконечная петля) или
**горизонтальное долгое видео** (1920×1080, 6–7 минут, главы с таймкодами в описании).
В каждое длинное видео сразу после хука автоматически вставляется **интро канала**
(9 с, вариант Pulse: «All That Matters. The channel where you learn how your own body works…»).
Файл интро — `remotion/public/brand/intro.mp4`; если поменять его код (`remotion/src/brand/Intro.tsx`),
программа перерендерит интро сама. Без интро исходник сохраняется как `video_main.mp4`.

## 4. Что лежит в папке ролика

`output/<дата>_<тема>/`:

| Файл | Что это |
|---|---|
| `video.mp4` | готовое видео 1080×1920 (Shorts) или 1920×1080 с интро (длинное) |
| `captions.srt` | субтитры для загрузки в YouTube |
| `thumbnail.png` | обложка |
| `title.txt` | 3 варианта названия (≤ 60 символов) |
| `description.txt` | описание с источниками и дисклеймером |
| `tags.txt` | теги |
| `sources.txt` | научные источники + какое утверждение на каком источнике держится + лицензии материалов |
| `script.txt` | текст озвучки с источниками |
| `storyboard.json` | подтверждённая раскадровка |
| `state.json` | состояние (на каком шаге ролик) |
| `log.txt` | журнал работы на русском |
| `voice.wav`, `words.json` | озвучка и время каждого слова |

## 5. Правила контента (соблюдаются автоматически)

- Только образовательное объяснение: без диагнозов, лечения, дозировок лекарств и добавок.
- Каждый факт — из научного обзора/мета-анализа (PubMed), NIH, WHO, Mayo Clinic или учебника.
- Каждый факт помечен: **доказано / предварительные данные / миф**.
- Простой язык: понятно даже ребёнку, термины объясняются сразу.
- «Educational, not medical advice» — в описании и на последнем кадре.
- Подробно: `docs/MEDICAL_RULES.md`, `docs/PLAIN_LANGUAGE.md`.

## 6. Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| На странице «Шаг не удался» | Нажмите «Повторить». Подробности — в журнале под кнопкой |
| Страница не открывается | Проверьте, что окно `start.bat` открыто; откройте `http://localhost:8765` вручную |
| `[!!] nvidia-smi не найден` | Всё работает на процессоре, просто медленнее. Обновите драйвер NVIDIA |
| Windows: «Интеллектуальное управление приложениями заблокировало файл» | В папке проекта: «Открыть в терминале» → `Get-ChildItem -Recurse \| Unblock-File`, затем запускайте `.\setup.bat` / `.\start.bat` из терминала |
| Агенты не работают | В PowerShell наберите `claude` и проверьте, что вы вошли в аккаунт |
| `claude : The term 'claude' is not recognized` | Проверьте `Test-Path "$env:USERPROFILE\.local\bin\claude.exe"`. Если `True` — добавьте папку в PATH: `[Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path", "User") + ";$env:USERPROFILE\.local\bin", "User")` и переоткройте PowerShell. Если `False` — установка не завершилась: поставьте через `winget install Anthropic.ClaudeCode` |
| `claude.exe ... is not a valid application for this OS platform` | Удалите npm-версию (`npm uninstall -g @anthropic-ai/claude-code`) и поставьте официальную: `winget install Anthropic.ClaudeCode`, затем переоткройте PowerShell |
| Голос с ошибками в редких словах | Установите eSpeak-NG (см. установку) |

## 7. Настройки

- Голос, скорость речи: `pipeline/tts.py` (`DEFAULT_VOICE = "am_fenrir"`, `SPEED = 0.92`).
- Цвета, шрифты, безопасная зона: `remotion/src/style.ts`.
- Длина ролика: `pipeline/job.py` (`MIN_SEC, MAX_SEC = 30, 55`).
- Музыка: по умолчанию нет. Можно положить свой трек **только CC0** в `remotion/public/music/` и записать его в `sources.txt`.
