# Фабрика исторических видео

Программа на вашем ноутбуке делает длинные (8–9 минут) YouTube-видео по истории на английском:
предлагает тему, пишет и проверяет текст, озвучивает, рисует карты и схемы, подбирает архивные
изображения с открытой лицензией и собирает готовое видео с обложками, описанием и Shorts.
Каждый важный шаг ждёт вашего решения на веб-странице.

Нужно: Windows 11, свободные 25 ГБ на диске C:, интернет на время установки, подписка Claude
(агенты фабрики работают через Claude Code и тратят её лимит).

---

## Установка (один раз, около 30–60 минут)

1. Нажмите **Win + X** → **«Терминал»**.
2. Если Git ещё не установлен, выполните и затем закройте и снова откройте Терминал:

   ```
   winget install Git.Git
   ```

3. Скачайте проект на диск C: — не на Рабочий стол, не в OneDrive, без русских букв в пути:

   ```
   git clone -b claude/nifty-bell-79c69y https://github.com/adilgaji/main C:\history-factory
   ```

4. Разблокируйте файлы и запустите установку:

   ```
   cd C:\history-factory
   Get-ChildItem -Recurse | Unblock-File
   .\setup.bat
   ```

   `setup.bat` сам поставит Python 3.12, Node.js, FFmpeg, Claude Code, библиотеки и модели голоса.
   Если он попросит **закрыть окно и запустить setup.bat ещё раз** — так и сделайте: Windows видит
   новые программы только в новом окне. Установка продолжится с места остановки. Оборвалась связь —
   тоже просто запустите `setup.bat` ещё раз.

5. Один раз войдите в Claude Code: в Терминале введите `claude` и следуйте подсказкам.

6. **По желанию — ускорение на видеокарте** (озвучка быстрее): запустите `install_gpu.bat`.
   Скачает около 3 ГБ. Нужен драйвер NVIDIA версии 580 или новее — файл сам проверит и подскажет.
   Если видеокарта не заработает, фабрика сама продолжит на процессоре.

На Рабочем столе появится ярлык **History Factory**.

## Каждый день

Дважды щёлкните **History Factory** на Рабочем столе (или `start.bat` в папке проекта).
Откроется страница в браузере. **Чёрное окно не закрывайте**, пока работаете: это и есть фабрика.
Закончили — закройте окно.

### Как сделать видео

На странице нажмите **«Начать новое видео»** (направление и подсказку к теме можно не указывать).
Дальше — 7 шагов, они видны сверху:

| Шаг | Что делает фабрика | Что делаете вы |
|---|---|---|
| 0. Стиль | показывает один кадр в 8 стилях | выбираете стиль (или оставляете основной) |
| 1. Тема | агент предлагает 5 тем с источниками | выбираете номер или просите другие |
| 2. План | агент составляет главы и собирает источники | «Принять» или «Переделать» с пожеланием |
| 3. Текст | сценарист пишет, проверка фактов сверяет с источниками | читаете текст и таблицу фактов; принимаете |
| 4. Озвучка и раскадровка | озвучивает, ищет картинки в музейных архивах, раскладывает кадры | слушаете голос, смотрите кадры; принимаете |
| 5. Производство | рендер по главам, склейка, проверки — без остановок | ждёте; время рендера показано заранее |
| 6. Упаковка и Shorts | названия, описание с главами, теги, 3 обложки, 3–5 Shorts, итоговая проверка | смотрите и принимаете |

Пожелания можно писать по-русски. Долгие шаги идут в фоне — в полосе сверху видно, что сейчас
делается, есть кнопка «Остановить». Остановленный или прерванный шаг при повторном запуске
продолжается с места остановки (готовые главы заново не рендерятся).

### Где готовые файлы

`C:\history-factory\output\<дата>_<тема>\` (кнопка «открыть папку» на странице):
`video.mp4`, `thumbnail_1..3.png`, `title.txt`, `description.txt` (с главами), `tags.txt`,
`captions.srt`, `sources.txt`, `shorts\short_1..5.mp4` с текстами. Загрузка на YouTube — вручную.

### Настройки

Вкладка **«Настройки»** на странице: голос (с кнопками «прослушать»), скорость речи, основной стиль,
ключ архива Smithsonian (бесплатный, по желанию) и кнопка **«Проверить компьютер»**.

## Обновление

Закройте окно страницы и запустите `update.bat`. Он скачает новую версию и доустановит библиотеки.
Ваши настройки, словарь произношений и память структур сохраняются (копия — в `logs\backup`).

---

## Если что-то не работает

- **.bat-файл не запускается** (Windows «Интеллектуальное управление приложениями»): правой кнопкой
  по пустому месту в папке проекта → **«Открыть в терминале»** → `Get-ChildItem -Recurse | Unblock-File`.
- **Проверка компьютера**: `check_env.bat` или кнопка на странице «Настройки». `[НЕТ!]` — нужно
  исправить, рядом написана готовая команда. Отчёт — `logs\env_report.json`.
- **Шаг завершился с ошибкой**: на странице нажмите «Показать журнал». Журналы лежат в `logs\`.
  Пришлите текст ошибки Claude.
- **Claude Code** ставьте только через `winget install Anthropic.ClaudeCode` (версия из npm на Windows
  не работает: «claude.exe is not a valid application»).

## Честно об ограничениях

- Агенты тратят лимит вашей подписки Claude. Тестовый ролик на 2,5 минуты обошёлся примерно в $2,3
  по оценке самого Claude Code; полное видео — дороже. Сумма видна на странице каждого видео.
- Сколько займёт рендер 8–9 минут видео на ноутбуке, станет известно после первого видео: скорость
  замеряется и дальше показывается на странице заранее.
- Remotion бесплатен для частных лиц и компаний до 3 человек.
- edge-tts (запасной голос Microsoft) включается, только если не работают Kokoro и Piper, и требует интернета.
