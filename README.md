# HSK 4 — тренер (подготовка к новому HSK 4 за 16 недель)

Приложение работает на твоём ноутбуке и открывается в браузере (и с телефона по Wi-Fi). Интерфейс на русском.

## Установка (один раз)
1. Установи Python 3.11 или новее с python.org. **Важно:** при установке поставь галочку «Add Python to PATH».
2. Распакуй/скопируй папку проекта куда удобно, например `C:\hsk4`.
3. Включи VPN (нужен для озвучки и установки библиотек).
4. Дважды щёлкни `start.bat`. Первый запуск 2–5 минут: ставятся библиотеки, потом открывается браузер.
   Если Windows спросит про брандмауэр — «Разрешить» (частная сеть), иначе телефон не подключится.

## Каждый день
1. Запусти `start.bat`, не закрывай чёрное окно.
2. Открой вкладку **«Сегодня»**: там блоки на ~2 часа. Иди сверху вниз, нажимай «Начать».
3. В первый день — **входной тест** (~10 минут). Он определит, сколько слов ты знаешь, и построит план.
4. Если пропустил день — ничего делать не надо: план сам пересчитается (больше новых слов в день, строка «Отставание» покажет цифры).
5. Раз в неделю в Claude Code: `/hsk-week` (отчёт и корректировка), `/hsk-refill` (новые задания под твои слабые места), `/hsk-check` (проверка письменных ответов и говорения — когда эти модули будут готовы).

## Озвучка
При запуске в фоне открывается маленькое окно «Озвучка»: оно скачивает голоса edge-tts (нужен VPN). Пока файлов нет, слова озвучивает браузер (качество ниже). Если окно написало про ошибку — включи VPN и перезапусти `start.bat`.

## Говорение (микрофон)
При первом запуске в фоне скачивается модель распознавания речи (~1,6 ГБ, нужен VPN; окно «Модель речи» можно свернуть). На ноутбуке с видеокартой она работает на GPU, иначе — на процессоре (медленнее). Запись: вкладка «Ещё» → в плане блок «Говорение». На ноутбуке микрофон работает на `http://localhost:8765`.

## Как открыть с телефона
1. Телефон и ноутбук — в одной Wi-Fi сети.
2. В чёрном окне `start.bat` или во вкладке «Ещё» найди адрес вида `http://192.168.x.x:8765`.
3. Открой его в браузере телефона. «Добавить на главный экран» сделает иконку-закладку.
   Для записи голоса с телефона открой адрес **https://192.168.x.x:8766** (тот же IP). Браузер скажет, что сертификат не доверенный — нажми «Дополнительно → Всё равно перейти»: это твой собственный ноутбук. Без https микрофон на телефоне не включается.

## Если что-то не работает
| Симптом | Что делать |
|---|---|
| «Python не найден» | Поставь Python, галочка «Add Python to PATH», запусти снова |
| Не ставятся библиотеки | Включи VPN, запусти снова; удали папку `.venv` и повтори |
| Страница не открывается | Окно start.bat должно быть открыто; адрес `http://localhost:8765` |
| С телефона не открывается | Одна Wi-Fi сеть; разреши брандмауэр; проверь адрес во вкладке «Ещё» |
| Нет звука на ноутбуке | Проверь громкость; в Chrome/Edge должен быть китайский голос Windows (Настройки → Язык) |
| «Озвучка: ошибка» | Включи VPN, перезапусти `start.bat` |
| Всё сломалось | Сфотографируй окно, покажи Claude. Прогресс лежит в файле `hsk.db` — копируй его для резервной копии |
