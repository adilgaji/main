description: Сгенерировать новые задания под слабые места (по статистике из БД) с автопроверкой
---
Ты пополняешь банк заданий HSK 4 тренера. Контент генерируешь ты (без платных API), проверяет скрипт.

1. Запусти `python tools/report.py` и прочитай: слабые типы карточек (`accuracy_by_kind`), слова с частыми ошибками (`stats.hard_words`), аудирование (`stats.listening_acc`, `hard_listening`), слова без примеров (`content.words_without_examples_priority`, сначала те, у кого уже есть карточка).
2. Реши баланс (аргумент пользователя: $ARGUMENTS; по умолчанию ~60 предложений-примеров + ~20 заданий на аудирование). Больше аудирования, если точность < 75%; больше примеров для слов с ошибками и для слов, которые скоро вводятся.
3. Пиши ТОЛЬКО так:
   - Примеры: новый файл `content/src/examples_NNN.jsonl` (следующий номер), по строке `{"w":"слово из content/words.json","zh":"предложение","ru":"перевод"}`. Предложение — естественное, 8–20 знаков, только лексика HSK 1–4 (список `content/allowed_words.txt`); имена только из `content/whitelist.txt`.
   - Аудирование: новый файл `content/src/listening_NNN.json`, формат как в `listening_001.json`: `id` (следующие L0xx), `type` dialog|passage, `turns` [{spk:F|M, zh}], `question`, 4 `options`, `answer` (индекс), `explain` (по-русски), `level`. Вариативность: разные темы (работа, быт, здоровье, поездки, учёба, покупки), правильный ответ в разных позициях, отвлекающие варианты правдоподобны. Формат заданий сверяй с `EXAM_SPEC.md` (пометки «не подтверждено» сохраняются).
4. Запусти `python tools/validate_content.py`. Исправь ВСЕ замечания (слово выше HSK 4 — перепиши предложение, не добавляй слово в whitelist ради обхода; неверный пиньинь — исправь контекст). Повторяй до `с проблемами: 0`.
5. Запусти `python -m pytest -q tests`.
6. Загрузи в БД: `python -c "from app import db; c=db.connect(); db.init(c)"`. Напомни пользователю, что озвучка новых заданий создастся при ближайшем start.bat (или `python tools/build_audio.py`).
7. Коммит и итог: сколько добавлено, какие слабые места закрыты, что осталось без примеров. Без воды.
