# Шрифты

Все шрифты распространяются по лицензии SIL Open Font License 1.1
(https://openfontlicense.org) — их можно свободно использовать и вкладывать в проект.
Файлы взяты из пакетов @fontsource / @fontsource-variable (npm), сами пакеты — в devDependencies.

| Шрифт | В каких стилях | Авторы |
|---|---|---|
| Playfair Display | Документальный (заголовки) | The Playfair Display Project Authors |
| Source Sans 3 | Документальный, Музей ночью (текст) | Adobe (Source Sans Project Authors) |
| Inter | субтитры и подписи, служебные надписи листов; Карта-объяснялка, Изометрия | The Inter Project Authors |
| EB Garamond | Пергамент и чернила | Georg Duffner, Octavio Pardo |
| Fredoka | Книжная иллюстрация (заголовки) | The Fredoka Project Authors |
| Nunito | Книжная иллюстрация, Бумажная аппликация (текст) | The Nunito Project Authors |
| Bricolage Grotesque | Бумажная аппликация (заголовки) | The Bricolage Grotesque Project Authors |
| Oswald | Старая кинохроника (заголовки) | The Oswald Project Authors |
| Courier Prime | Старая кинохроника (текст и субтитры) | Quote-Unquote Apps |
| Space Grotesk | Карта-объяснялка (заголовки) | The Space Grotesk Project Authors |
| Sora | Изометрия (заголовки) | The Sora Project Authors |
| Cormorant | Музей ночью (заголовки) | The Cormorant Project Authors |

Загружаются только шрифты выбранного стиля (`video/src/fontFaces.ts`).
