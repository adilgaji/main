# Шрифты

Все шрифты распространяются по лицензии SIL Open Font License 1.1
(https://openfontlicense.org) — их можно свободно использовать и вкладывать в проект.
Файлы взяты из пакетов @fontsource-variable (npm).

| Шрифт | Где используется | Авторы |
|---|---|---|
| Playfair Display | заголовки, цитаты | The Playfair Display Project Authors |
| Source Sans 3 | подписи, пояснения | Adobe (Source Sans Project Authors) |
| Inter | субтитры | The Inter Project Authors |
