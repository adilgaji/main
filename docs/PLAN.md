# План проекта «Фабрика исторических видео»

Правила проекта — в `CLAUDE.md`. Здесь — этапы, структура и текущий статус.

## Этапы разработки

После каждого этапа: запуск → тест → показ результата → ждём «ок» владельца.

| № | Этап | Что увидит владелец | Статус |
|---|------|---------------------|--------|
| 0 | Проверка окружения, план, структура | отчёт проверки, этот план | готово |
| 1 | Голоса | 6 образцов Kokoro на одном отрывке + словарь произношений → выбор голоса | ждёт выбора голоса |
| 2 | Библиотека визуала | тестовый лист 1920x1080: карта, таймлайн, рассказчик, Ken Burns, цитата, инфографика | — |
| 3 | Стили | один и тот же кадр в 8 стилях → подтверждение | — |
| 4 | Одна глава (60–90 с) | ролик с озвучкой, субтитрами, архивными изображениями и `sources.txt` | — |
| 5 | Шаги 1–4 сценария работы | тема (даёт владелец) → план → текст → раскадровка | — |
| 6 | Полное видео 8–9 минут | `video.mp4` по подтверждённой раскадровке | — |
| 7 | Упаковка | обложки, названия, описание с главами, теги, `.srt`, Shorts | — |
| 8 | Веб-страница и установка | страница со всеми шагами 0–6, `setup.bat`, README, `CLAUDE.md` | — |

## Как устроена работа над одним видео

```
тема → план → текст → [озвучка + время слов] → раскадровка → производство → результат
 └ агент  └ агент └ агент + fact-checker  └ скрипт        └ агент        └ скрипты + агенты
```

1. **Сначала звук, потом картинка.** Как только текст подтверждён, скрипт сразу озвучивает
   его и получает от Kokoro точное время каждого слова. Раскадровка привязывает каждый кадр
   к конкретным словам, поэтому картинка, субтитры и главы не могут «уехать» от голоса,
   а время в раскадровке — настоящее, а не оценка.
2. **Рендер по главам.** Каждая глава — отдельный файл. Сбой на 5-й главе не трогает
   готовые 1–4; повторный запуск продолжает с места сбоя. Затем склейка без перекодирования.
3. **Тексты отдельным слоем.** Обработка стиля (сепия, зерно, бумага) применяется к картинке;
   заголовки, подписи и субтитры рисуются поверх и всегда чёткие.
4. **Проверки — скриптами, а не «на глаз».** Длительность видео = звук = сумма кадров;
   громкость; субтитры = текст; у каждой картинки лицензия; таймкоды глав ± 1 с.
5. **Агенты пишут файлы, скрипты их проверяют.** Агент возвращает JSON; скрипт сверяет его
   со схемой и при ошибке возвращает агенту на исправление (до 3 раз).

## Честные оговорки

- **Разработка идёт в облаке (Linux, без видеокарты).** `.bat`-файлы и ускорение на
  видеокарте проверяются только на ноутбуке владельца.
- **Remotion** бесплатен для частных лиц и компаний до 3 человек; для компаний крупнее
  нужна платная лицензия.
- **edge-tts** — онлайн-голос Microsoft: нужен интернет, включается только как последний
  резерв, если не работают ни Kokoro, ни Piper. Запасные движки подключаются на этапе 4.
- **Субагенты Claude Code** тратят лимит подписки Claude владельца.
- **Время рендера** 8–9 минут видео заранее неизвестно — измеряется на этапах 2 и 4 и
  показывается на странице.
