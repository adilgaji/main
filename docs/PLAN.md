# План: фабрика YouTube Shorts «Биология тела»

## Где что работает
- **Разработка и тесты** — в облаке Claude (здесь нет видеокарты, всё на процессоре).
- **Боевой запуск** — на вашем ноутбуке (RTX 4050, 6 ГБ). Код сам находит видеокарту;
  при ошибке CUDA переключается на процессор.

## Структура проекта
```
bodyshorts/
  remotion/            видео-движок (React + Remotion)
    src/style.ts       единая палитра, шрифты, безопасная зона
    src/lib/           стикмен (8 поз, 5 эмоций), схемы: тело, сердце, мозг,
                       мышца, клетка, молекула гормона, стрелки, график, иконки
    src/scenes/        типы кадров (зум тело→орган→клетка, график, стикмен+текст…)
    src/Captions.tsx   «караоке»-субтитры по словам
  pipeline/            Python-скрипты (не агенты)
    tts.py             озвучка: Kokoro (GPU) → Piper → edge-tts
    captions.py        faster-whisper, тайминги каждого слова (GPU → CPU)
    render.py          рендер Remotion, проверки (громкость, длительность, кадр)
    package.py         названия, описание, теги, thumbnail.png
    run_job.py         шаг 4 целиком, 3 попытки на шаг, лог на русском
  web/                 веб-страница (FastAPI + простой HTML) с кнопками шагов 1–5
  .claude/agents/      idea-researcher, scriptwriter, fact-checker,
                       storyboard-agent, quality-reviewer
  output/<дата>_<тема>/  state.json, script.txt, storyboard.json, voice.wav,
                       words.json, video.mp4, thumbnail.png, title/description/tags.txt,
                       sources.txt, log.txt
```

## Как веб-страница вызывает агентов
Страница запускает `claude -p` (Claude Code в режиме без диалога) с нужным субагентом.
Агент пишет результат в файл папки ролика, страница показывает его и ждёт вашей кнопки.
Агенты не задают вопросов — только вы через страницу.

## Ограничения и решения
- Kokoro требует Python 3.10–3.12 → проект использует Python 3.12 в отдельном venv.
- В облаке закрыт HuggingFace (оттуда качаются Kokoro, Piper и Whisper модели).
  На вашем ноутбуке доступ есть. Для тестов здесь — либо открыть доступ, либо
  временно edge-tts / espeak.
- edge-tts — бесплатный, но онлайн-сервис Microsoft: только третий запасной вариант.
- Музыка: по умолчанию без музыки (можно положить свой CC0-трек в `assets/music/`
  с записью в sources.txt).
- Безопасная зона Shorts 1080×1920: сверху 220 px, снизу 420 px, справа 160 px
  (кнопки лайк/комментарии) — важное только внутри.
