Ты — старший инженер. Построй автономный проект: фабрика длинных
(8–9 минут) горизонтальных YouTube-видео в нише ИСТОРИЯ. Я не программист:
объясняй просто, на русском. Видео — на английском.

ОГРАНИЧЕНИЯ
Только бесплатные открытые инструменты, всё работает локально на моём
ноутбуке. Никаких платных API, подписок, внешних генераторов картинок/видео/
голоса. Единственный «умный» компонент — Claude Code (субагенты через
`claude -p --agent ...`).

МОИ ОТВЕТЫ (не переспрашивай)
- Язык видео: английский. Длина: 8–9 минут (~1250–1400 слов озвучки).
- Формат: горизонтальный 16:9, 1920x1080, 30 fps.
- Ниша: история, четыре поднаправления (выбираются для каждого видео):
  древние цивилизации; войны и сражения; загадки и тайны истории;
  повседневная жизнь людей в прошлом.
- Визуал: СМЕШАННЫЙ — анимированные карты и таймлайны кодом + архивные
  изображения ТОЛЬКО public domain / CC0 с плавным движением камеры
  (Ken Burns) + иллюстрации кодом (персонажи, схемы, сцены).
- Музыки НЕТ. Только голос (звуковые эффекты — только если я попрошу позже).
- Голос: на первом этапе покажи 4–6 бесплатных голосов Kokoro
  (например am_fenrir, am_michael, bm_george, bm_fable, af_heart, bf_emma)
  на одном и том же историческом отрывке — я выберу. Выбор хранится в настройках
  и может меняться для отдельного видео.
- Работает на ноутбуке: Windows 11, NVIDIA GeForce RTX 4050 Laptop (6 ГБ).
  GPU — где ускоряет, с автоматическим откатом на CPU при ошибке.
- Дополнительно: 3–5 вертикальных Shorts из каждого видео; 2–3 варианта
  обложки; выбор визуального стиля с картинками-примерами.

СТЕК
- Remotion (React) для видео. Установи Remotion и его skill для Claude Code
  (`npx skills add remotion-dev/skills`) и следуй его правилам.
- Python 3.12 (Kokoro не работает на 3.13+), отдельный .venv.
- Озвучка Kokoro (kokoro==0.9.4). ВАЖНО: время каждого слова бери прямо из
  Kokoro (result.tokens: start_ts/end_ts) — НЕ используй faster-whisper/
  ctranslate2: на Windows 11 «Интеллектуальное управление приложениями»
  (Smart App Control) блокирует его DLL (WinError 4551). Запасные движки
  озвучки: Piper, затем edge-tts.
- Произношение: исторические имена и места (Hatshepsut, Thermopylae,
  Tenochtitlan…) — словарь произношений (misaki поддерживает
  [слово](/фонемы/)); агент проверяет все имена собственные в тексте и
  добавляет их в словарь.
- FFmpeg для сборки, громкости и проверок.
- Веб-страница: FastAPI + один HTML-файл, запуск двойным щелчком start.bat.

ИЗОБРАЖЕНИЯ И ИСТОЧНИКИ (строго)
- Внешние изображения — ТОЛЬКО public domain или CC0. Источники с открытыми
  API и понятными лицензиями: Wikimedia Commons (проверять лицензию через
  API metadata, брать только PD/CC0), The Met Open Access (CC0), Art Institute
  of Chicago (CC0), Smithsonian Open Access (CC0), Rijksmuseum (CC0),
  Library of Congress (только «no known restrictions», с проверкой).
  Каждый файл: URL, автор, дата, лицензия → sources.txt. Нет лицензии — нет
  файла. Скачанное кэшируется.
- Карты: современная география из Natural Earth (public domain); исторические
  границы рисуются кодом по источникам и подписываются «approximate».
- Без лиц реальных живых людей, без чужих логотипов и кадров из фильмов/
  других каналов.

ПРАВИЛА ИСТОРИЧЕСКОГО КОНТЕНТА (строго)
- Каждый факт, дата, число и цитата — с надёжным источником, который агент
  реально открыл: научные книги и статьи (университетские издательства,
  JSTOR/открытые статьи), энциклопедии (Britannica, World History
  Encyclopedia с осторожностью), сайты музеев и архивов, первоисточники.
  Блоги, форумы, «топ-10» сайты, YouTube и соцсети — не источники.
- Разделять: установленный факт / спорно (историки расходятся) / легенда /
  миф. Спорное и легенды так и называются в озвучке.
- Числа (армии, жертвы, население) — с диапазоном и источником, без
  преувеличений.
- Тяжёлые темы (войны, геноциды, рабство, казни) — уважительно, без
  смакования насилия, без героизации преступлений, без оправдания
  ненависти; соответствие правилам YouTube о насилии и экстремизме.
- Без «презентизма»-оценок без пояснений; не выдавать догадки за факты.
- Простой язык: понятно школьнику; термины и имена объясняются сразу
  («a pharaoh — Egypt's king»). Автопроверка простоты текста.

СЦЕНАРИЙ И УДЕРЖАНИЕ (длинное видео)
- Хук в первые 15 секунд: интрига/вопрос/неожиданный факт, обещание
  ответа, без кликбейта.
- Каждые 60–90 секунд — «повторный хук» (новый вопрос, поворот, открытая
  петля), чтобы зритель не ушёл.
- У КАЖДОГО видео своя структура (хроника, расследование загадки,
  «день из жизни», «взлёт и падение», «миф vs правда», «5 причин…»,
  «глазами участника», «что если…», «сравнение эпох», обратный отсчёт и т.п.).
  Фабрика помнит последние структуры и не повторяет их подряд.
- 5–7 глав, у каждой своя мини-кульминация.
- Финал: вывод + мост к следующей теме, без «подпишитесь» в середине.

ВИЗУАЛ
- Кадр всегда заполнен: крупный главный объект, «среда»-фон, движение
  камеры. Никаких пустых экранов с маленькой фигуркой.
- У каждого кадра свой фон; соседние кадры никогда не одинаковые.
- Смена картинки каждые 4–8 секунд (для длинного видео), разные типы кадров:
  карта с анимированными стрелками и границами, таймлайн, архивное
  изображение с Ken Burns и подписью, сцена-иллюстрация кодом, персонаж-
  рассказчик, сравнение «тогда/сейчас», цитата из первоисточника, схема
  (битвы, города, торговые пути), инфографика с числами.
- Субтитры снизу (2 строки, крупно, с подсветкой слова) + файл .srt для
  YouTube. Всё важное — в безопасной зоне.
- Стили на выбор (как минимум 6, предложи свои): например documentary
  (архив + Ken Burns), parchment & ink, illustrated (персонажи кодом),
  paper-cut, retro newsreel (сепия, зерно плёнки), map-explainer, isometric.
  ПЕРЕД тем как встраивать выбор стиля — покажи мне один и тот же кадр в
  каждом стиле и жди моего подтверждения.
- Единые палитры/шрифты в style.ts; стили меняют палитру, шрифт и обработку
  картинки, но тексты (заголовки, подписи, субтитры) всегда чёткие —
  рисуются отдельным слоем поверх обработки.

ГЛАВНЫЙ СЦЕНАРИЙ РАБОТЫ (веб-страница; каждый шаг ждёт моего решения;
состояние в output/<дата>_<тема>/state.json)
0. Первый экран: выбор стиля (картинки-примеры) и голоса (кнопки «прослушать»),
   кнопка «Запустить».
1. Тема: «Ввести сам» или «Найти автоматически» (idea-researcher ищет, что
   сейчас ищут и смотрят по истории, предлагает ОДНУ тему с обоснованием,
   поднаправлением и уникальным углом; «Подтвердить» / «Сделать заново» без
   повторов).
2. План: 5–7 глав, у каждой — суть, ключевые факты, повторный хук,
   предполагаемые источники и визуалы. «Подтвердить» / «Переделать» (с
   замечаниями) / «Править вручную».
3. Текст по главам: озвучка + русский перевод для меня + таблица
   «утверждение → статус (факт/спорно/легенда/миф) → источник». Можно
   переписать отдельную главу.
4. Раскадровка по главам: время, что на экране, точный текст, переход,
   найденные изображения с лицензией (превью). Правка отдельных кадров.
   «Подтвердить и начать работу».
5. Производство (без вопросов): озвучка → время слов → изображения →
   рендер ПО ГЛАВАМ (параллельно и с возможностью продолжить после сбоя) →
   склейка → проверки → обложки, названия, описание, теги → Shorts →
   контроль качества. Прогресс и оценка оставшегося времени на странице;
   упавший шаг повторяется до 3 раз; лог на русском.
6. Результат: видео, 2–3 обложки, 3 названия, описание с источниками, теги,
   .srt, список Shorts с превью, отчёт контроля качества, «Открыть папку».

ТЕХНИЧЕСКИЕ УРОКИ (обязательно учти — это уже ломалось у меня раньше)
- Windows-установка: setup.bat + start.bat + update.bat (git pull).
  Claude Code ставить через `winget install Anthropic.ClaudeCode` (npm-версия
  даёт «claude.exe is not a valid application»). Скачанные .bat блокирует
  Smart App Control → в README инструкция «Открыть в терминале» →
  `Get-ChildItem -Recurse | Unblock-File` → `.\setup.bat`. Папка проекта —
  на диске C: (не Рабочий стол/OneDrive, без кириллицы в пути).
- Медленный интернет: pip с `--resume-retries 100 --timeout 120`; PyTorch по
  умолчанию обычный (≈200 МБ), версия для видеокарты — отдельным
  install_gpu.bat; модели скачиваются заранее отдельной командой с
  докачкой.
- Рендер Remotion: на Windows сначала `--gl=angle` (видеокарта), затем
  `swiftshader`; на Linux без GPU — `swiftshader`/`egl` (НЕ `swangle`, он в 4 раза
  медленнее). Шум/зерно — готовые картинки-текстуры, а не feTurbulence в
  каждом кадре. Итоговый файл — H.264 yuv420p (не yuvj420p) с
  `-movflags +faststart`, иначе не открывается на телефонах.
- Громкость −16…−13 LUFS, пики ≤ −1 dB; видео = звук = сумма кадров;
  субтитры = текст на 100%.
- Время рендера 8–9 минут видео: показывай оценку; рендер по главам, чтобы
  сбой не начинал всё заново.

соответствует подтверждённой раскадровке; Shorts самодостаточны и с хуком.
