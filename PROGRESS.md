## Не проверено (честно)
- **Пробник — не точная копия экзамена.** Структура (32/32/6 заданий, 20/30/25 мин), порядок разделов и шкала — допущения по сторонним источникам. Банк мал: аудирование 30 из 32, чтение 52 вопроса. Устная часть сдаётся отдельно, не в пробнике.
- Качество распознавания реальной китайской речи: в песочнице не было китайского аудио (фейковый микрофон = гудок). Точность на `large-v3-turbo` и на GPU RTX 4050 не измерена; Windows-DLL для CUDA (`nvidia-cublas-cu12`, `nvidia-cudnn-cu12`) — вслепую, при сбое приложение уйдёт на процессор (медленнее, ~10 с на фразу с tiny; small/CPU дольше).
- https-сервер из start.bat на Windows и микрофон на реальном телефоне.
- `start.bat` не запускался на Windows (писал вслепую).
- edge-tts: реальную генерацию озвучки не проверял — из песочницы нет доступа к серверам Microsoft; проверена только логика (`--fake`). До первой генерации звучит голос браузера.
- Телефон по Wi-Fi: проверен только bind на 0.0.0.0, реального телефона не было. Service worker/PWA-установка по `http://IP` не заработают (нужен https — теперь есть порт 8766 с самоподписанным сертификатом, на нём сервис-воркер Chrome всё равно блокируется из-за ошибки сертификата; иконка «на экран» работает как закладка).
- Официальный формат HSK 4 и проходной балл — не подтверждены (сайты недоступны).
